## Security Model

CorvusTunnel implements defense-in-depth with the following layers:

### End-to-End Encryption (E2E)
- **Key exchange**: X25519 Diffie-Hellman via PyNaCl/libsodium during QR code scanning
- **Message encryption**: NaCl SecretBox (XSalsa20-Poly1305)
- **What's encrypted**: All user prompts, agent responses, file contents, terminal I/O
- **What's NOT encrypted**: Message timestamps, sizes, connection metadata

### Authentication
- **Boot token**: One-time-use, cryptographically random (48-byte URL-safe), delivered via QR code
- **Session token**: Issued after boot token claim, used for all subsequent API calls
- **IP binding**: Session is bound to the claiming IP address
- **WebSocket tickets**: One-time, IP-bound, 30-second TTL

### Network Security
- **Cloudflare Tunnel**: TLS-encrypted tunnel, no open inbound ports
- **CORS**: Restricted (no credentials)
- **Rate limiting**: Per-endpoint via slowapi
- **IP auto-ban**: After repeated authentication failures
- **Body size limits**: Per-endpoint maximum request sizes
- **Security headers**: HSTS, X-Content-Type-Options, X-Frame-Options

### Process Isolation
- **Non-root execution**: Server runs as dedicated `corvus` user (Docker)
- **Workspace sandboxing**: Only directories in `ALLOWED_DIRS` are accessible
- **Path traversal prevention**: All paths validated against whitelist roots

## Reporting a Vulnerability

**Please do NOT create public GitHub issues for security vulnerabilities.**

Email: **security@kalai-tech.com**

For more information, visit: [Security at KALAI](https://kalai-tech.com/security)

We will:
1. Acknowledge your report within 48 hours
2. Provide an initial assessment within 5 business days
3. Work with you on a fix and coordinated disclosure

## Security Checklist for Self-Hosting

- [ ] Use a strong, random `AGENT_TOKEN` (auto-generated by default)
- [ ] Keep `ALLOWED_DIRS` minimal — only the workspace you need
- [ ] Run behind Cloudflare Tunnel (never expose port 8000 directly)
- [ ] Monitor audit logs in `./logs/`
- [ ] Keep CorvusTunnel updated (`pip install --upgrade corvustunnel`)
- [ ] Use named Cloudflare Tunnels for persistent URLs (Pro feature)
